# Showcase

My portfolio: a one-page site with the projects I've built since I started programming.

Built with plain HTML, CSS and JavaScript, using [AOS](https://michalsnik.github.io/aos/) for the scroll animations and [simpleParallax](https://simpleparallax.com/) for the project images. The "Other Github Repos" list is loaded from the GitHub API.

## Running locally

Any static server works, for example:

```bash
npx http-server -p 8000
```
